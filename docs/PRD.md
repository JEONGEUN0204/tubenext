# PRD: TubeNext

## 목표
내 유튜브 채널의 콘텐츠 정체성을 파악하고, 같은 주제에서 지금 터지고 있는 영상을 근거로 "다음에 만들 영상" 기획안을 제안한다.

## 사용자
채널을 운영 중이며 다음 영상 주제를 정하는 데 시간을 쓰는 1인 크리에이터.

## 핵심 기능
1. **채널 분석** — `@핸들` 또는 채널 URL 입력 → 최근 업로드 30개의 제목·조회수·길이·업로드 주기에서 채널 프로필(니치, 타깃, 주력 포맷, 평균 조회수, 검색 키워드)을 도출한다.
2. **바이럴 탐색** — 채널 프로필에서 뽑은 키워드로 최근 30일 한국(`regionCode=KR`) 영상을 검색하고, 구독자 대비 조회수 배율로 랭킹해 상위 영상을 보여준다.
3. **다음 콘텐츠 추천** — 채널 프로필 + 바이럴 영상 목록을 근거로 제목·훅·구성·참고한 바이럴 영상이 붙은 기획안 5개를 생성한다.

## MVP 제외 사항
- 로그인/OAuth — 공개 데이터만 읽는다. 내 채널의 비공개 애널리틱스는 다루지 않는다.
- DB·분석 히스토리 저장 — 결과는 요청할 때마다 새로 계산한다.
- 썸네일 이미지 분석, 댓글 분석, 경쟁 채널 추적, 업로드 스케줄링.
- 다중 채널 비교, 시계열 차트 대시보드.

## 디자인
- 다크모드 고정. 마케팅 페이지가 아니라 매일 여는 데이터 도구처럼 보일 것.
- 무채색 기반 + 데이터 강조색 2개(상승=초록, 배율=앰버)만 사용.
