## 배경 (이 phase 전체의 목적)

Anthropic API 크레딧이 소진되거나 키가 없을 때도 앱이 끝까지 동작해야 한다.
현재 `src/services/claude.ts`의 `extractProfile`이 실패하면 검색 키워드가 없어 파이프라인 전체가 502로 죽는다.
이 phase는 **LLM 없이 규칙만으로 채널 프로필과 기획안을 만드는 대체 경로**를 만든다.
이 step은 그 대체 경로의 가장 아래 조각인 **한국어 제목 키워드 추출기**다.

형태소 분석기 패키지를 설치하지 마라. 의존성 0으로 만든다.

## 작업

`src/lib/keywords.ts` 하나만 만든다. 순수 함수만 둔다.

### 공개 API

```ts
export interface ExtractOptions {
  excludeTokens?: string[]; // 이 토큰들은 후보에서 뺀다 (채널명 토큰 등)
  limit?: number;           // 반환 개수. 기본 3
}

/** 제목 1개 → 원시 토큰 배열 (조사 정규화 전) */
export function tokenizeTitle(title: string): string[];

/** 제목 여러 개 → 조사 정규화까지 끝난 토큰 배열들 */
export function tokenizeTitles(titles: string[]): string[][];

/** 제목 여러 개 → 검색에 쓸 키워드 상위 N개 */
export function extractKeywords(titles: string[], options?: ExtractOptions): string[];
```

### `tokenizeTitle` 규칙

1. 한글(가-힣)·영문·숫자가 아닌 모든 문자를 공백으로 치환한다. 이모지, `[]`, `()`, `|`, `#`, `·`, `-`, `/`, 문장부호가 전부 여기서 사라진다.
2. 공백으로 split하고 빈 문자열을 버린다.
3. 영문은 소문자로 통일한다.
4. 아래를 버린다:
   - 길이 1 토큰
   - 숫자만으로 이루어진 토큰 (`2024`, `3000`)
   - 불용어(STOPWORDS)
5. **조사 제거는 여기서 하지 않는다.** `tokenizeTitles`의 2번째 패스에서 한다. 이유는 아래에 있다.

STOPWORDS는 "검색창에 넣어도 같은 주제 영상이 안 나오는 일반어"만 넣는다. 최소한 아래를 포함하라:

```
영상, 채널, 구독, 좋아요, 댓글, 오늘, 어제, 내일, 진짜, 정말, 완전, 그냥, 이거, 저거,
우리, 내가, 제가, 너무, 이번, 다음, 여러분, 사람, 시간, 마지막, 최초, 공개, 대박,
레전드, 역대급, 실화, 근황, shorts, short, vlog, ep, part, full, official, mv, tv
```

`브이로그`, `리뷰`, `먹방`, `챌린지`, `튜토리얼` 같은 **포맷 단어는 불용어가 아니다.** 실제 검색에 쓰이는 유효 키워드다. 넣지 마라.

### `tokenizeTitles` — 조사 정규화 2패스

한국어 조사를 무조건 떼면 멀쩡한 명사가 깨진다. `고양이` → `고양`, `포도` → `포`.
그래서 **전체 제목에서 모은 토큰 집합을 근거로만** 조사를 뗀다.

- 1패스: 모든 제목을 `tokenizeTitle`로 돌려 토큰 배열들과 전체 토큰 집합 `seen`을 만든다.
- 2패스: 각 토큰에 아래 순서로 정규화를 적용한다.

**2자 조사** — `에서`, `으로`, `에게`, `한테`, `부터`, `까지`, `처럼`, `보다`, `라도`, `이라는`, `라는`
- 토큰 길이가 4 이상이고, 떼고 난 어간 길이가 2 이상이면 **무조건 뗀다.**
- 이유: 이 음절쌍으로 끝나는 한국어 명사는 사실상 없다. `쿠팡에서` → `쿠팡`.

**1자 조사** — `은`, `는`, `이`, `가`, `을`, `를`, `의`, `에`, `도`, `만`, `로`, `와`, `과`
- 토큰 길이가 3 이상이고, 떼고 난 어간 길이가 2 이상이고, **그 어간이 `seen`에 이미 있을 때만** 뗀다.
- 이유: `고양이`는 `고양`이 다른 제목에 단독으로 등장한 적이 없으므로 그대로 남는다. `김치를`은 다른 제목에 `김치`가 있으면 `김치`로 합쳐진다. 30개 제목이면 반복 소재는 대개 단독으로도 등장한다.
- **이 규칙을 "길이 4 이상이면 무조건 뗀다"로 바꾸지 마라.** `고양이`·`돼지고기`·`김치찌개`류가 전부 깨진다.

정규화 후 다시 STOPWORDS와 길이 1을 걸러낸다.

### `extractKeywords` 규칙

1. `tokenizeTitles`로 정규화된 토큰 배열들을 얻는다.
2. `options.excludeTokens`에 있는 토큰을 제거한다. 비교는 소문자 기준 정확 일치다.
   - 이유: 채널명·진행자 이름이 키워드에 들어가면 내 채널 영상만 다시 검색된다. 이건 LLM 프롬프트(`src/services/claude.ts`의 system)에도 박혀 있는 규칙이다.
3. **바이그램**(한 제목 안에서 연속한 두 토큰을 `"a b"`로 join) 빈도를 센다. **2회 이상** 등장한 것만 후보다.
4. **유니그램** 빈도를 센다. 1회짜리도 후보다.
5. 정렬: 바이그램 후보를 빈도 내림차순으로 먼저, 그다음 유니그램 후보를 빈도 내림차순으로. 빈도가 같으면 **먼저 등장한 순서**를 유지한다 (결정적 출력. 테스트가 흔들리면 안 된다).
6. 이미 고른 키워드에 문자열로 포함되는 후보는 건너뛴다. 예: `"자취 요리"`를 골랐으면 `자취`와 `요리`는 건너뛴다.
   - 이유: 검색 키워드 3개가 사실상 같은 검색이 되면 `search.list` 100 units를 낭비한다.
7. `limit`(기본 3)개를 반환한다. 후보가 모자라면 있는 만큼만 반환한다. 입력이 비었으면 빈 배열이다.

바이그램을 우선하는 이유: 한 단어보다 2~3어절 구가 실제 YouTube 검색어에 가깝다. 이것도 LLM 프롬프트에 있는 규칙과 같다.

## 테스트 — `tests/keywords.test.ts`

**TDD다. 테스트를 먼저 쓰고, 통과하는 구현을 써라** (CLAUDE.md CRITICAL).
`lib/`은 순수 함수라 mock이 필요 없다. 네트워크도 `process.env`도 건드리지 않는다.

최소한 아래를 덮어라:

- `tokenizeTitle`: `"[3천원 자취] 김치볶음밥 만들기 #shorts"` → 특수문자·`shorts`·숫자만 토큰이 사라지고 `자취`, `김치볶음밥`, `만들기`가 남는다
- 1자 조사: `["김치를 볶았다", "김치 맛있게"]` → `김치를`이 `김치`로 합쳐진다
- 1자 조사 보호: `["고양이 밥주기", "고양이 간식"]` → `고양`이 아니라 `고양이`가 나온다 (어간 `고양`이 집합에 없다)
- 2자 조사: `["쿠팡에서 산 물건", ...]` → `쿠팡`
- `excludeTokens`: 채널명 토큰이 결과에서 빠진다
- 바이그램 우선: 같은 두 단어가 연속으로 2번 이상 나오면 `"a b"` 형태가 유니그램보다 먼저 나온다
- 포함 중복 제거: 바이그램이 뽑힌 뒤 그 구성 단어가 따로 나오지 않는다
- `limit`: 기본값이 3이고, 후보가 1개뿐이면 1개만 반환한다
- 빈 입력 / 특수문자뿐인 제목 → 빈 배열 (예외를 던지면 안 된다)

## 금지사항

- 형태소 분석기 패키지(`mecab`, `hangul-js`, `es-hangul` 등)를 설치하지 마라. 이유: ADR 철학이 외부 의존성 최소화다. 제목 30개에서 빈출어를 뽑는 데 형태소 분석기까지 필요하지 않다.
- 1자 조사를 길이·`seen` 조건 없이 무조건 떼지 마라. 이유: `고양이`→`고양`, `이야기`→`이야` 같은 명사 훼손이 그대로 검색 키워드가 되어 엉뚱한 영상이 검색된다.
- `src/services/`, `src/app/`, `src/components/`, `src/types/`를 수정하지 마라. 이유: 이 step의 범위는 `src/lib/keywords.ts`와 그 테스트뿐이다. 타입 변경은 step 4에서 한다.
- 기존 `src/lib/*.ts`를 수정하지 마라. 이유: 이 step은 새 파일만 추가한다.
- 기존 테스트를 깨뜨리지 마라.
